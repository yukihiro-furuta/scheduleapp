## 1. ユーザーストーリー

| ID | ユーザーストーリー |
|---|---|
| US-01 | ユーザーとして、カレンダーの日付をクリックして予定を素早く追加したい。なぜなら、入力の手間を最小化したいから。 |
| US-02 | ユーザーとして、月間カレンダーで全ての予定を一覧したい。なぜなら、今月の忙しさを視覚的に把握したいから。 |
| US-03 | ユーザーとして、予定のステータスを「予定→進行中→完了」に変更したい。なぜなら、進捗を管理したいから。 |
| US-04 | ユーザーとして、ステータスで予定を絞り込みたい。なぜなら、今やるべきことだけに集中したいから。 |
| US-05 | ユーザーとして、カレンダー上でイベントをドラッグして日程を変更したい。なぜなら、変更操作を直感的に行いたいから。 |
| US-06 | ユーザーとして、スマートフォンからも快適に操作したい。なぜなら、外出先でも確認・更新したいから。 |

## 2. イベント管理（CRUD）

### 2.1 イベント作成（Create）

- 新規作成ボタンからモーダルフォームを開いて入力できる
- カレンダーの日付セルをクリックすると、その日付が開始日に自動入力された状態でモーダルが開く
- 入力後、保存ボタンで登録される

### 2.2 イベント参照（Read）

- **カレンダービュー**: 月間グリッド形式で、各日にイベントチップとして表示
- **リストビュー**: 開始日の昇順でイベントを一覧表示
- ステータスフィルターで絞り込み可能

### 2.3 イベント更新（Update）

- カレンダーのイベントチップ、またはリストの編集ボタンからモーダルを開いて編集できる
- 全項目を変更可能

### 2.4 イベント削除（Delete）

- リストビューの削除ボタンから削除できる
- 削除前に確認ダイアログを表示する（誤操作防止）

## 3. イベント項目定義

| 項目名 | 型 | 必須 | バリデーション | 説明 |
|---|---|---|---|---|
| タイトル | 文字列 | ✓ | 最大100文字 | イベントの名称 |
| 説明 | 文字列 | — | 最大500文字 | 詳細メモ |
| 開始日 | 日付（YYYY-MM-DD） | ✓ | 有効な日付 | イベント開始日 |
| 終了日 | 日付（YYYY-MM-DD） | — | 開始日以降 | 複数日イベントの終日。省略時は開始日のみ |
| 開始時刻 | 時刻（HH:MM） | — | 有効な時刻 | 省略時は「終日」扱い |
| 終了時刻 | 時刻（HH:MM） | — | 開始時刻以降 | 開始時刻を入力した場合に設定可能 |
| ステータス | 選択肢 | ✓ | 下記3値のいずれか | デフォルト: `planned` |

---

## 4. ステータス定義

| 値 | 表示名 | 説明 |
|---|---|---|
| `planned` | 予定 | まだ開始していない予定 |
| `in_progress` | 進行中 | 現在進行中のイベント |
| `completed` | 完了 | 終了したイベント |

---

## 5. カレンダービュー（SCR-01）

- 月間グリッド（7列 × 最大6行）を表示する
- ヘッダーに前月（‹）・翌月（›）ナビゲーションボタンと「今日」ボタンを設ける
- 各日のセルに、その日に該当するイベントをチップ形式で表示する
  - 複数日イベント（終了日あり）はすべての該当日に表示する
  - 1セルに最大3件表示し、超過分は「+N more」と表示する
- 今日の日付を視覚的にハイライトする
- ステータスフィルターによる絞り込みが反映される

---

## 6. リストビュー（SCR-02）

- すべてのイベントを開始日の昇順で一覧表示する
- 各イベントカードに以下を表示する

| 表示項目 | 表示条件 |
|---|---|
| タイトル | 常時 |
| 日付 | 終了日がある場合は「開始日 〜 終了日」形式、単日は「開始日」のみ |
| 時刻 | 終日の場合は「終日」と表示 |
| ステータスバッジ | 常時 |
| 説明 | 入力されている場合のみ |
| 編集ボタン | 常時 |
| 削除ボタン | 常時 |

- ステータスフィルターによる絞り込みに対応する

---

## 7. ステータスフィルター

- 「全て / 予定 / 進行中 / 完了」の4つのタブで絞り込みができる
- カレンダービュー・リストビューの両方に適用される
- デフォルト選択は「全て」

---

## 8. ドラッグ&ドロップによるイベント移動

- カレンダービュー上で、イベントチップを別の日付セルへドラッグして開始日を変更できる
- 複数日イベント（終了日あり）の場合、開始日〜終了日の期間を保ったまま移動する（日数差を維持）
- ドラッグ中は元のセルを薄く表示し、ドロップ可能なセルをハイライトする
- ドロップ後は即座に保存される
  - Phase 1: localStorage を更新
  - Phase 2: `PUT /api/events/{id}` を呼び出し
- Phase 1（バニラJS）・Phase 2（React）ともに HTML5 Drag and Drop API を使用する（外部ライブラリ不使用）

## 9. 受け入れ条件（Acceptance Criteria）

### Phase 1

| ID | 受け入れ条件 |
|---|---|
| AC-01 | カレンダービューに月間グリッドが表示され、前月・翌月に移動できる |
| AC-02 | 日付セルをクリックするとイベント作成モーダルが開き、その日が開始日に自動入力される |
| AC-03 | イベントを作成後、カレンダーとリストの両方に反映される |
| AC-04 | イベントを編集・削除できる（削除前に確認ダイアログが表示される） |
| AC-05 | ステータスフィルターでカレンダー・リスト双方の表示が絞り込まれる |
| AC-06 | カレンダー上でイベントをドラッグして別日に移動できる |
| AC-07 | スマートフォン幅（767px 以下）でリストビューが正常に表示・操作できる |
| AC-08 | ブラウザをリロードしても登録済みイベントが消えない（localStorage 永続化） |

### Phase 2

| ID | 受け入れ条件 |
|---|---|
| AC-09 | Phase 1 の全受け入れ条件（AC-01〜08）を React 実装で満たす |
| AC-10 | `docker compose up` 一コマンドでアプリが起動する |
| AC-11 | ブラウザを閉じてもデータが PostgreSQL に保持される |
| AC-12 | REST API（GET/POST/PUT/DELETE）が仕様通りに動作する |
