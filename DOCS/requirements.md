## 1. プロジェクト概要

### 1.1 背景と課題

現状、個人のスケジュール管理は市販のカレンダーアプリや手書きのメモに頼っているが、以下の課題が生じている。

- 予定の**進行状況（着手済み・完了）が一目で分からない**
- 複数日にまたがる予定が視覚的に把握しにくい
- PC・スマートフォン双方で快適に操作できるツールが少ない

### 1.2 目的

イベント・予定を日付ベースで登録・管理できるスケジュール管理アプリを構築する。  
カレンダー形式で予定を視覚的に把握し、ステータス管理によって予定の進行状況を追跡できることを目的とする。

### 1.3 期待効果

- 予定の抜け漏れを防ぎ、当日・翌日にやるべきことを即座に確認できる
- 「予定 → 進行中 → 完了」のステータス遷移により、タスク消化の達成感を得られる
- PC・スマートフォンどちらからも快適に操作できる

### 1.4 利用者

- **利用者**: 開発者本人のみ（個人利用）
- **同時利用人数**: 1名
- **認証**: 不要

### 1.5 開発フェーズ

| フェーズ | 内容 | 技術概要 |
|---|---|---|
| Phase 1 | バニラJSプロトタイプ | HTML / CSS / JavaScript / localStorage |
| Phase 2 | フルスタック実装 | React + TypeScript / Spring Boot + PostgreSQL |

詳細は [技術スタック](tech-stack.md) を参照。

## 3. 機能概要

詳細は [機能要件定義書](functional-spec.md) を参照。

| 機能 | 概要 |
|---|---|
| イベント作成 | カレンダーの日付クリックまたは新規作成ボタンからモーダルで登録 |
| イベント参照 | カレンダービュー（月間グリッド）とリストビューで表示 |
| イベント編集 | チップまたはリストの編集ボタンからモーダルで変更 |
| イベント削除 | リストの削除ボタンから確認ダイアログ経由で削除 |
| ステータス管理 | 予定 / 進行中 / 完了 の3種類 |
| フィルタリング | ステータスタブでカレンダー・リスト両方を絞り込み |
| ドラッグ&ドロップ | カレンダー上でイベントをドラッグして日程変更 |
