## 2. 画面遷移

```
[SCR-01 カレンダービュー] ←→ [SCR-02 リストビュー]  ← ビュー切り替えタブ
       │                              │
       │ 日付セルクリック              │ 編集ボタンクリック

       ▼                              ▼

     元の画面へ戻る                  元の画面へ戻る
```

## 3. SCR-01 カレンダービュー

### 3.1 ワイヤーフレーム

```
┌─────────────────────────────────────────────────────────┐
│  スケジュール管理              [カレンダー] [リスト]      │  ← ヘッダー
│  フィルター: [全て] [予定] [進行中] [完了]                │  ← フィルタータブ
├─────────────────────────────────────────────────────────┤
│  ‹  2026年11月  ›                   [今日] [+ 新規作成]  │  ← カレンダーヘッダー
│  ─────────────────────────────────────────────────────  │
│   日    月    火    水    木    金    土                   │
│  ─────────────────────────────────────────────────────  │
│   1     2     3     4     5     6     7                  │
│         [週次MTG  ]                                       │
│  ─────────────────────────────────────────────────────  │
│   8     9    10    11    12    13    14                   │
│               [プレゼン準備        ]                      │
│               [+1 more]                                  │
│  ─────────────────────────────────────────────────────  │
│  15    16    17    18   [19]   20    21                   │  ← 今日をハイライト
│                                                          │
│  ─────────────────────────────────────────────────────  │
│  22    23    24    25    26    27    28                   │
│                                                          │
│  ─────────────────────────────────────────────────────  │
│  29    30                                                │
└─────────────────────────────────────────────────────────┘
```

### 3.2 各要素の仕様

| 要素 | 仕様 |
|---|---|
| ビュー切り替えタブ | 「カレンダー」「リスト」の2タブ。現在のビューがアクティブ表示 |
| フィルタータブ | 「全て / 予定 / 進行中 / 完了」の4タブ |
| 月ナビゲーション | ‹（前月）・›（翌月）ボタンと現在月の表示 |
| 今日ボタン | クリックで今月のカレンダーに戻る |
| 新規作成ボタン | クリックでSCR-03を開く |
| 日付セル | クリックでSCR-03を開き、クリックした日付を開始日に自動入力 |
| イベントチップ | タイトルとステータス色を表示。クリックでSCR-04を開く |
| +N more | 表示上限（3件）を超えた場合に表示 |
| 今日のハイライト | 今日の日付セルを視覚的に強調（背景色・テキスト色） |

### 3.3 イベントチップのステータス色

| ステータス | 色 |
|---|---|
| 予定（planned） | 青系 |
| 進行中（in_progress） | 黄・オレンジ系 |
| 完了（completed） | 緑系 |

## 4. SCR-02 リストビュー

### 4.1 ワイヤーフレーム

```
┌─────────────────────────────────────────────────────────┐
│  スケジュール管理              [カレンダー] [リスト]      │
│  フィルター: [全て] [予定] [進行中] [完了]                │
├─────────────────────────────────────────────────────────┤
│  ┌───────────────────────────────────────────────────┐  │
│  │ 週次ミーティング                        [予定]    │  │
│  │ 2026-11-25（火） 10:00〜11:00                     │  │
│  │ 議事録をまとめる                                  │  │
│  │                                      [編集] [削除] │  │
│  └───────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────┐  │
│  │ プレゼン資料作成                      [進行中]    │  │
│  │ 2026-11-26（水）〜 11-28（金）  終日               │  │
│  │                                      [編集] [削除] │  │
│  └───────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────┐  │
│  │ 月次レポート提出                        [完了]    │  │
│  │ 2026-11-20（金） 終日                             │  │
│  │                                      [編集] [削除] │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

### 4.2 各要素の仕様

| 要素 | 仕様 |
|---|---|
| イベントカード | 開始日の昇順で並ぶ |
| 日付表示 | 終了日がある場合は「開始日 〜 終了日」、単日は開始日のみ |
| 時刻表示 | 開始時刻がない場合は「終日」と表示 |
| ステータスバッジ | カード右上に色付きバッジで表示 |
| 編集ボタン | クリックでSCR-04を開く |
| 削除ボタン | クリックで確認ダイアログを表示し、OKで削除 |

## 5. SCR-03 イベント作成モーダル

### 5.1 ワイヤーフレーム（PC表示）

```
┌──────────────────────────────────────────┐
│  新規イベント作成                      ✕  │
├──────────────────────────────────────────┤
│  タイトル *                               │
│  ┌────────────────────────────────────┐  │
│  │                                    │  │
│  └────────────────────────────────────┘  │
│  説明                                     │
│  ┌────────────────────────────────────┐  │
│  │                                    │  │
│  │                                    │  │
│  └────────────────────────────────────┘  │
│  開始日 *              終了日             │
│  ┌──────────────┐     ┌──────────────┐  │
│  │ 2026-11-25   │     │              │  │
│  └──────────────┘     └──────────────┘  │
│  開始時刻              終了時刻           │
│  ┌──────────────┐     ┌──────────────┐  │
│  │ 10:00        │     │ 11:00        │  │
│  └──────────────┘     └──────────────┘  │
│  ステータス *                             │
│  ○ 予定   ○ 進行中   ○ 完了             │
├──────────────────────────────────────────┤
│                   [キャンセル]  [保存]    │
└──────────────────────────────────────────┘
```

### 5.2 スマートフォン表示

- 画面下部からスライドアップして表示（ボトムシート形式）
- 全項目は縦方向に1カラムで並べる

### 5.3 バリデーション

| 項目 | ルール | エラーメッセージ例 |
|---|---|---|
| タイトル | 必須・最大100文字 | 「タイトルを入力してください」 |
| 開始日 | 必須・有効な日付 | 「開始日を入力してください」 |
| 終了日 | 開始日以降 | 「終了日は開始日以降を入力してください」 |
| 終了時刻 | 開始時刻以降 | 「終了時刻は開始時刻以降を入力してください」 |

## 6. SCR-04 イベント編集モーダル

- SCR-03と同一レイアウト
- モーダルタイトルが「イベントを編集」に変わる
- 既存の値がフォームに初期表示される

---

## 7. レスポンシブ対応方針

| 画面幅 | デフォルト表示 | 備考 |
|---|---|---|
| PC（768px 以上） | SCR-01 カレンダービュー | タブでリストビューへ切り替え可能 |
| スマホ（767px 以下） | SCR-02 リストビュー | タブでカレンダービューへ切り替え可能 |

- ボタン・タップ領域は最小 44 × 44px を確保する
- スマホではモーダルをボトムシート形式で表示
